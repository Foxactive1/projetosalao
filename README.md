# InNovaIdeia® Salon

Aplicativo Android de demonstração para salão de beleza, em Kotlin e Jetpack Compose.

## Interface
- Identidade InNovaIdeia® com paleta azul-marinho e azul tecnológico
- Tema claro/escuro
- Navegação inferior: Início, Produtos, Serviços e Perfil
- Catálogo demonstrativo e cards reutilizáveis

## Execução
Abra o repositório no Android Studio, sincronize o Gradle e execute o módulo `app`.

## Limitações
Dados em memória. Sem autenticação, API, checkout ou agendamento persistente nesta etapa.
A implementação anterior foi preservada nos demais arquivos; a nova entrada está em `MainActivity.kt`.
